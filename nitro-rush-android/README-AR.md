# NITRO RUSH — ملف أندرويد APK

لعبة سيارات عربية تعمل داخل تطبيق Android مستقل. ملفات اللعبة كاملة داخل حزمة APK؛ بعد التثبيت لا تحتاج اتصالًا بالإنترنت.

## بناء APK من GitHub
1. ادخل إلى تبويب **Actions** في المستودع.
2. اختر **NITRO RUSH - Build Android APK**.
3. افتح التشغيل الناجح، ثم حمّل الملف **NITRO-RUSH-APK** من قسم Artifacts.
4. فك ضغط الملف، وثبّت **NITRO-RUSH.apk** على هاتفك.
5. يمكن تنزيل APK مباشرةً من تبويب **Releases** عند نجاح النشر الاختياري.

## ملاحظات
- تطبيق NITRO RUSH منفصل عن تطبيق DeutschB1Trainer الموجود في جذر المستودع.
- Gradle 8.9 / Android Gradle Plugin 8.7.0 / Java 17 / compileSdk 35.
- المعرف: `com.nitrorush.ar`.
- APK مبني بوضع debug وموقّع للتثبيت والاختبار؛ لا يُستخدم كإصدار متجر نهائي.
- التقدم محفوظ على الهاتف في WebView Local Storage. حذف بيانات التطبيق يحذف التقدم.
- التحكم باللمس، المرآب، العملات، النيترو، ومراحل السباق كلها تعمل محليًا دون خادم.
